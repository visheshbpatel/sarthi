# Sarthi

Sarthi is an AI-powered personal assistant built with n8n.

It uses an AI agent to understand natural-language requests and interact with different tools and services such as Gmail, Google Calendar, Google Tasks, Notes, Google Search, and expense tracking.

## Features

- AI-powered natural language interaction
- Gmail integration
- Google Calendar integration
- Google Tasks integration
- Notes management
- Google Search
- Expense tracking
- Webhook-based communication
- Tool-based AI agent workflow

## Tech Stack

- n8n
- LLM
- Webhooks
- Gmail
- Google Calendar
- Google Tasks
- Google Sheets
- Google Docs
- Google Search

## Architecture

```text
User
  ↓
Frontend
  ↓
Webhook
  ↓
AI Agent
  ↓
Tools
 ├── Gmail
 ├── Calendar
 ├── Tasks
 ├── Notes
 ├── Search
 └── Expense Tracking
  ↓
Response
  ↓
Frontend
```
